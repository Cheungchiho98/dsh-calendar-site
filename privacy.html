隐私权政策

DSH 日历与任务 · 最后更新：2026 年 11 月 25 日

一、适用范围

本政策适用于「DSH 日历与任务」（以下简称"本工具"）。本工具为个人自用软件，仅供账号所有者本人操作自己的 Google 账号数据，不向公众提供服务。

二、访问的数据

经您明确授权后，本工具访问以下数据：

  • Google 日历：日历列表、事件标题、时间、地点、描述、参与者
  • Google Tasks：任务列表、任务标题、备注、截止日期、完成状态

本工具不访问 Gmail、Google Drive、通讯录或任何其他 Google 服务的数据。

三、数据如何存储

所有数据仅保存在您本人的计算机上：

  • OAuth 访问令牌与刷新令牌保存在本机配置目录，文件权限仅限当前用户读取
  • 日历与任务内容仅在处理请求时于内存中使用，不写入任何远端数据库

四、数据是否共享

不共享。本工具不会将您的数据出售、出租、转让或以任何形式提供给第三方。除与 Google 官方 API 通信以完成您请求的操作外，不进行任何数据传输。

五、Google API 服务用户数据政策

本工具对 Google API 的使用遵循 Google API 服务用户数据政策，包括其中的有限使用要求（Limited Use requirements）。

六、数据保留与删除

  • 您可以随时在 Google 账号权限页面 撤销本工具的访问授权
  • 撤销授权后，本工具即无法再访问任何数据
  • 本机保存的令牌可随时手动删除，删除后授权状态随之失效

七、安全

本工具与 Google API 的通信均通过 HTTPS 加密传输。令牌存储于本机，不通过网络传输至任何第三方服务器。

八、儿童隐私

本工具不面向 13 岁以下儿童，也不会有意收集儿童信息。

九、政策变更

如本政策发生变更，将更新本页面并修改"最后更新"日期。
